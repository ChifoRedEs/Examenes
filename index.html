Crear tests

Sube archivos con tus preguntas. Se guardan en este navegador y aparecen en el menú, dentro de su categoría.

    Copia de seguridad

    Descarga tus tests propios y tus estadísticas, o restáuralos en otro navegador o dispositivo.

    Formato del archivo TXT

    Una etiqueta entre corchetes por línea. Cada pregunta empieza con [Pregunta] y termina con [Correcta]. Admite de 2 a 6 opciones (A–F).

    [Categoria] Celador
[Titulo] Tema 1 Celador

[Pregunta] ¿Cuál grupo de medicamentos es el más comúnmente implicado en una caída?
[A] Antihistamínicos de primera generación
[B] Antidiabéticos orales
[C] Vasodilatadores
[D] Benzodiacepinas
[Correcta] D

    Formato del archivo JSON

    Un objeto con categoria, titulo y la lista preguntas. El campo explicacion es opcional.

    {
  "categoria": "Celador",
  "titulo": "Tema 1 Celador",
  "preguntas": [
    {
      "id": 1,
      "texto": "¿Cuál grupo de medicamentos ...?",
      "opciones": {
        "A": "Antihistamínicos de primera generación",
        "B": "Antidiabéticos orales",
        "C": "Vasodilatadores",
        "D": "Benzodiacepinas"
      },
      "correcta": "D"
    }
  ]
}
